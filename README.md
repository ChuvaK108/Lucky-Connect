# Lucky Connect - Футуристичный VPN Клиент

## Описание

Lucky Connect - это современный VPN клиент для Android с уникальным футуристичным дизайном, который выделяется среди конкурентов. Приложение создано с использованием Jetpack Compose и следует принципам Material Design 3.

## Особенности дизайна

### 🎨 Футуристичная цветовая палитра
- **Cyber Blue** (#00D4FF) - основной акцентный цвет
- **Neon Green** (#39FF14) - для успешных состояний
- **Electric Purple** (#8A2BE2) - для дополнительных акцентов
- **Laser Red** (#FF073A) - для ошибок и предупреждений
- **Quantum Gold** (#FFD700) - для премиум функций

### ✨ Уникальные UI элементы
- **Неоновые карточки** с эффектом glassmorphism
- **Анимированная кнопка подключения** с пульсирующим свечением
- **Вращающиеся кольца** во время подключения
- **Градиентные фоны** с эффектом глубокого космоса
- **Пульсирующие эффекты** для важных элементов

## Функциональность

### 🔐 VPN Возможности
- Подключение к различным серверам по всему миру
- Поддержка протоколов WireGuard, OpenVPN, IKEv2
- Kill Switch для безопасности
- DNS защита от утечек
- Блокировщик рекламы

### 📊 Статистика
- Скорость загрузки и отдачи в реальном времени
- Время подключения
- Пинг до сервера
- Общий объем переданных данных

### ⚙️ Настройки
- Автоподключение при запуске
- Выбор протокола VPN
- Настройки безопасности
- Управление подпиской

## Архитектура

Приложение построено с использованием современных Android технологий:

- **Jetpack Compose** - для создания UI
- **MVVM** - архитектурный паттерн
- **StateFlow** - для управления состоянием
- **Navigation Compose** - для навигации
- **Material Design 3** - дизайн система

## Структура проекта

```
app/src/main/java/com/example/luckyconnect/
├── data/
│   ├── VpnModels.kt          # Модели данных
│   └── VpnRepository.kt      # Репозиторий для данных

├── ui/
│   ├── theme/

│   │   └── Type.kt           # Типографика

│   ├── screens/

│   │   ├── ServersScreen.kt  # Экран выбора серверов
```

## Экраны приложения

### 🏠 Главный экран
- Большая анимированная кнопка подключения
- Информация о выбранном сервере
- Статистика подключения (при активном VPN)
- Быстрые действия (серверы, настройки)

### 🌍 Экран серверов
- Список серверов по регионам
- Поиск и фильтрация
- Индикаторы пинга и загрузки
- Отметки оптимальных и премиум серверов

### ⚙️ Экран настроек
- Переключатели для различных опций
- Выбор протокола VPN
- Информация о приложении
- Управление подпиской

## Установка и запуск

1. Клонируйте репозиторий
2. Откройте проект в Android Studio
3. Синхронизируйте Gradle файлы
4. Запустите приложение на эмуляторе или устройстве

## Требования

- Android API 26+ (Android 8.0)
- Kotlin 1.8+
- Jetpack Compose 1.5+
